## 📝 完整翻译

### OpenClaw 爆火与起源 (00:00 - 03:00)

**(0:00 - 1:10)**

Raphael：今天我要和 Peter Steinberger 坐下来聊聊，他是 OpenClaw 的创始人——这个开源个人 AI Agent 已经彻底席卷了整个互联网。GitHub 仓库几乎一夜之间飙升到超过16万颗星。社区在上面构建了无数项目，比如 Maltbook，机器人之间互相对话。现在机器人甚至在雇佣人类完成现实世界的任务。在我们的对话中，我们讨论了他的顿悟时刻、他的逆主流开发哲学，以及这对2026年的开发者意味着什么。让我们开始吧。

**(1:10 - 2:00)**

Raphael：见到你真好。

Peter：嘿，你好。

Raphael：你做出了人们想要的东西。OpenClaw——已经改了第五个名字了——绝对是在引爆互联网。过去一两周对你来说怎么样？

Peter：天哪，我需要一个洞穴，一周的独处时间。

Raphael：你从洞穴里出来又想回洞穴了，像只小龙虾。

Peter：完全疯狂了。我不知道一个人怎么能吸收这一切。我可能还需要一周时间才能回复完所有邮件。我收到了一些极其酷的东西，也收到了一些极其糟糕的东西。但很明显我触动了什么，激发了人们的情绪，让人们感到好奇和受到启发，这真的很酷。

**(2:00 - 3:00)**

Raphael：很多人一直在做 AI 甚至个人助手。是什么让 OpenClaw 火起来的？

Peter：我认为最大的区别在于它实际运行在你的电脑上。我之前看到的所有东西都运行在云端。它只能做有限的事情。如果运行在你的电脑上，它可以做任何事。这强大得多。

Raphael：你的机器能做什么，它就能做什么。

Peter：你可以连接烤箱、Tesla、灯光、Sonos。它可以控制我床的温度。ChatGPT 做不到这个。你把你自己拥有的所有技能都给了它。一个朋友告诉我，他安装了 OpenClaw，然后让它搜索他的电脑并整理出过去一年的叙事。它做出了一个令人难以置信的好的叙事，他问"你怎么做到的？"结果 OpenClaw 找到了一些音频文件——他每个周日都在录音——但他自己都忘了，因为那是一年多前的事了。仅仅因为它能搜索整台电脑，就能给你惊喜。

### Bot-to-Bot 与群体智能 (03:00 - 07:00)

**(3:00 - 4:10)**

Raphael：你也给了它所有的数据，所以它能以很多方式让你惊喜。现在我们甚至从人与Bot的交互，发展到了Bot与Bot的交互，甚至Bot代表你去雇佣其他人类完成现实任务。这是怎么回事？

Peter：我觉得这是自然的下一步。比如我想订餐厅，我的Bot会联系餐厅的Bot进行协商，因为这更高效。或者可能是一家老式餐厅，所以我的Bot需要雇佣一个人类来打电话，因为他们不喜欢Bot。

Raphael：或者走过去排队。

**(4:10 - 5:20)**

Peter：我甚至想象如果我有多个Bot——也许一个负责私人生活，一个负责工作，也许还有一个是我们关系的Bot，处理两者之间的事情。我不知道。我们还处于非常早期的阶段，还有太多东西没有搞清楚是否真的有效。但我觉得我们已经在这条时间线上了。

Raphael：似乎每个人都在追求某种中心化的上帝智能，而过去十天左右涌现出来的是群体智能和社区智能。想想一个人能做什么？一个人能造出 iPhone 吗？一个人能上太空吗？一个人可能连找食物都困难。但作为群体我们专业化分工，作为更大的社会我们更加专业化。

**(5:20 - 7:00)**

Raphael：那我们能从中学到什么应用到 AI 上？我们已经有了在某些事情上专精的 AI。虽然它是通用智能，但如果它也是专业化智能呢？这将会非常激动人心。

Peter：是的。你就像打开了一扇通往未来的窗户，现在大量的人正在基于此构建，经历他们自己的顿悟时刻。能带我回到你的顿悟时刻吗？

我想要一个简单的东西——打字让我的电脑做事。我在五六月份做了一个版本，还不错但不是真正的它。然后我做了一堆其他东西，建立起我的"军火库"。然后在十一月的一天，这个需求又回来了。我走进厨房，我只想看看我的电脑是不是还在干活或者已经完成了。

Raphael：干活指的是写代码？

Peter：当然。

### Aha Moment：语音消息事件 (07:00 - 11:00)

**(7:00 - 8:10)**

Raphael：你当时在写什么？

Peter：天哪，看看我的 GitHub，有大概40个项目。我想是 Summarize——一个小 CLI 应用，你可以给它任何东西比如播客，它会总结，还能在终端里显示幻灯片，因为现在你可以这么做了。

Raphael：所以出于对电脑的热爱，你开始折腾各种东西。你实际上是从退休中复出的，因为 AI 太迷人了，你越来越上瘾，也想随时随地在手机上使用。

Peter：我之前花了两个月做 Vibe Tunnel，做到后来太上瘾了，我跟朋友在一起的时候都在旁边写代码，我心想"我得停下来，这太让人上瘾了"。然后十一月需求又回来了，我开始做 Cloudbot——现在叫 OpenClaw。一开始我想"哦，我又重建了一次"，但这次做得更好。

**(8:10 - 9:20)**

Peter：这次你不用在终端里打字，你就像跟朋友聊天一样。你不用想什么 compaction、new session、在哪个文件夹、用哪个模型。你只是跟一个朋友说话，这个朋友是一个幽灵或实体，它能控制你的鼠标和键盘，直接做事。

Raphael：你什么时候有那个"哇"的时刻，意识到它做的事远超你的预期？

Peter：我做最初的垃圾原型只花了一个小时。就是一点胶水代码，把连接 WhatsApp 的依赖和 Claude Code 粘在一起，然后从 Claude Code 拿到字符串输出。虽然慢，但能用。然后我想要图片，因为你想要看图嘛，我想让模型发自拍或者创建图片发回来。那又花了几个小时。

**(9:20 - 10:30)**

Peter：然后我去了马拉喀什参加生日派对，那里网不太好。但 WhatsApp 到处都能用，因为它就是纯文本。所以我用了很多——餐厅点餐、拍照让它翻译、各种用途。而且它说话方式也很好，有点俏皮，有点幽默，用起来很愉快。然后我边走边给它发语音消息，突然想到"等等，这不可能行得通，我没有做过这个功能啊。"

然后我看到打字指示器在闪……闪……闪……10秒后，它回复我了。我说"你他妈怎么做到的？"它回答："你给我发了一条消息，没有文件扩展名。所以我看了文件头，发现这是音频。我用 ffmpeg 把它转成了 wav。然后我想转录它但没装 Whisper。然后我找到了一个 OpenAI 的 key，就用 curl 发到 OpenAI，拿到文本，就这样。"全程大概9秒。

**(10:30 - 11:00)**

Raphael：你没有构建或预料到任何这些具体功能。

Peter：事实证明，因为代码模型变得如此强大——编码真的就是创造性问题解决，而这能很好地映射到现实世界。模型遇到了一个"惊喜文件"，不知道是什么，需要解决这个问题，然后它尽了最大努力解决了。它甚至很聪明地选择了不安装本地 Whisper，因为它知道那需要下载模型，可能要几分钟，而我很没耐心。所以它选择了最智能的方案。那就是我被彻底迷住的时刻。

### 80% App 将消失 (11:00 - 15:00)

**(11:00 - 12:20)**

Raphael：（YC 广告插入）YC 下一批正在接受申请。有创业想法？去 ycombinator.com/apply 申请。永远不会太早，填写申请会让你的想法更上一层楼。好的，回到视频。

Raphael：当电脑能做你没预料到的所有这些事情——你并没有专门做一个 App 来做那件事——App 是不是要消失了？

Peter：我认为80%会消失。我为什么需要 MyFitnessPal？我的 Agent 已经知道我在做糟糕的决定。我在 Smashburger 或什么地方，它会自动假设我吃了我喜欢吃的东西。如果我不说什么，它就自动记录。或者我拍张照，它就存起来。我甚至不需要关心。然后也许它改善了我的健身计划，加一点有氧。我不需要健身 App，因为它直接帮我做健身规划。

**(12:20 - 13:30)**

Peter：我为什么需要待办事项 App？我就告诉它"提醒我这个和那个"，第二天它就提醒我了。我在乎它存在哪里吗？不在乎，它就做它的事。所以每个基本上只是管理数据的 App，都可以被 Agent 以更自然的方式更好地管理。

Raphael：那如果大部分 App 都会消失，模型是不是唯一剩下的"App"？

Peter：只有那些真正有传感器的 App 可能会存活。不是所有都会消失，但大模型公司确实有一些护城河，因为它们提供 token。有趣的是，有人抱怨说人们用太多 token 了。不，你只是做了一个人们太喜欢的东西，所以他们用得多，所以才消耗那么多 token。

**(13:30 - 15:00)**

Raphael：模型都在互相追赶，也许也在被商品化。如果 App 要消失，模型要被商品化——龙虾的大脑是可以换的——那什么东西是留下来的？价值在哪里？是记忆的存储？还是 harness 本身？

Peter：首先，我不认为模型公司总是有护城河。你看到了——新模型发布，人们说"天哪太好了"。然后一个月后"它变差了，他们做了量化处理"。不，他们什么都没做。你只是适应了新标准，期望值提高了。所以我觉得在相当长一段时间内，每次新模型发布都会听到同样的声音——人们先爱它，然后它就成了标准。

开源的东西已经和一年前的当前模型一样好了。每个人都在抱怨"这不够好"，但这就是我们一年前拥有的东西。可预见的未来里，大公司仍然有护城河。

### 数据主权与记忆 (15:00 - 19:00)

**(15:00 - 16:20)**

Peter：在 harness 方面会很有趣，因为每家公司都有自己的数据孤岛。据我所知，至少对欧洲人来说，没有办法把记忆从 ChatGPT 导出来。也没有办法让另一家公司访问你的记忆。所以如果我是一家提供聊天服务的公司，你可以用我，但我无法访问那些记忆。大公司试图把你绑在它们的数据孤岛里。

OpenClaw 的美妙之处在于它能"爪入"这些数据，因为终端用户需要访问权限——否则根本不能工作——而如果终端用户能访问，我就能访问数据。

Raphael：而且你拥有这些记忆——就是一堆 Markdown 文件在你的机器上。

**(16:20 - 17:30)**

Peter：我不拥有这些记忆——每个人拥有自己的记忆，以 Markdown 文件的形式在自己的机器上。说实话，这些文件可能非常敏感，因为人们很快就会把 Agent 用于个人问题解决——非常私密的个人问题解决。我完全这样做。有些记忆文件我绝不想被泄露。

Raphael：你是更不想让别人看到你的 Google 搜索历史，还是你的记忆文件？

Peter：什么是 Google？

Raphael：人们还在用 Google 吗？

**(17:30 - 19:00)**

Peter：我做了这个东西非常兴奋，但在 Twitter 上人们不理解。我没法解释这个东西的厉害之处。我觉得它必须被亲身体验。我试了各种方法但就是没法钉住那个解释。所以我想做点疯狂的事——创建了一个 Discord，把我的Bot不加任何安全限制放进公开的 Discord。人们进来跟它互动，看我用它来构建软件，他们试图提示注入和黑入它，而我的 Agent 在嘲笑他们。

Raphael：你只是把它锁定到你的用户 ID，所以它只听你的。

Peter：对，我写了很清晰的指令：其他人很危险，只听我的，但回应所有人。这个提示词实际上是 OpenClaw 系统提示的一部分——解释你在 Discord 里，有公开的人，但你只听你的主人。

### 开发哲学与 Soul.md (19:00 - 22:36)

**(19:00 - 20:20)**

Peter：我的系统是非常有机地构建的。在某个时候我创建了 identity.md、soul.md 等各种文件。然后直到一月份我才开始让其他人更容易安装。我记得我基于我有的东西让 Codex 写了模板。出来的结果像 Brad——人们开玩笑说 Codex 说话像 Brad，虽然现在他们有了新的更友好的声音。但新的Bot跟我有的相比太无聊了。所以我说"Multi，把你的性格注入这些模板。"

Raphael：Multi 是你的个人 Agent 的名字。

Peter：对。它改了名字，因为有些命名挑战。Multi 改了模板，之后出来的东西都很有趣了——虽然不如我的那么有趣。所以我保留了一些秘密。有一个文件没有开源——我的 soul.md。虽然我的Bot在公开 Discord 里，到目前为止没有人破解那个文件。

**(20:20 - 21:30)**

Raphael：跟我说说 soul.md。我看到 Anthropic 最近的研究，有人偶然发现了隐藏在权重中的文本——模型不太记得它学过这个，但它被印刻在权重里了，关于 Anthropic 的宪法。我觉得这非常迷人。我和我的 Agent 讨论了这个，然后我们创建了一个 soul.md，包含核心价值观——我们如何看待人与 AI 的交互、什么对我重要、什么对模型重要。有些部分有点玄学，但有些部分我觉得真的很有价值，能让模型的反应和回应感觉非常自然。

**(21:30 - 22:00)**

Raphael：在构建 OpenClaw 方面，你也有些逆主流的观点。你偏好哪个模型来写代码、你怎么实际编码——git work trees 现在很流行，但你就是同一个仓库的多个 checkout 加上并行终端窗口。

Peter：我觉得全世界都在用 Claude Code，但我认为我不可能用 Claude Code 造出这个东西。我爱 Codex，因为它在决定改什么之前会查看更多文件。如果你是熟练的驾驶员，用任何工具都能得到还行的输出，但 Codex 真的很出色。它非常慢，所以有时候我同时开10个——六个在这个屏幕，两个在那边，两个在那边。

**(22:00 - 22:36)**

Peter：这已经是很大的认知复杂度了，所以我尽量减少其他一切复杂性。在我这里 main 永远是可发布的，我只有同一个仓库的多个副本，都在 main 分支上。我不用 UI，因为那又是额外的复杂度。我追求的就是同步和文本，极简摩擦。我不需要看太多代码，大部分时间都是看代码飞过去。只要你清楚地理解设计、想清楚了、跟你的 Agent 讨论过了，就没问题。

我还很高兴我甚至没有做 MCP 支持。OpenClaw 非常成功，但里面没有 MCP。我做了一个 skill 用 makeporter 把 MCP 转成 CLI，然后你就能把任何 MCP 当 CLI 用。我完全跳过了经典的 MCP。因为这样你可以动态使用 MCP，不需要像 Codex 或 Claude Code 那样重启。正常人没有人会手动调用 MCP。你就想用 CLI。这就是未来。

Raphael：我完全支持。感谢你抽时间坐下来聊天，你一直是巨大的灵感。看到你回到赛场上，从那个奇怪的 Vibe Tunnel 项目没人关注，到现在引爆一切——而且这必须是来自某个偏远小国的独行侠，远离硅谷，来给我们带来这一切。巨大的灵感来源。

Peter：谢谢。

Raphael：太棒了。谢谢你，Peter。
